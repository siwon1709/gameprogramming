
📘 게임 프로그래밍 레포트

1. 개발 환경
게임 프로그래밍의 기본 실습은 Dev-C++ 5.11과 TDM-GCC 4.9.2 컴파일러를 기반으로 진행된다. 이 환경은 C 언어를 활용한 콘솔 기반 게임 제작에 적합하며, 디버깅과 프로젝트 관리 기능을 제공한다.

2. 커서 제어
콘솔 화면에서 원하는 위치에 텍스트를 출력하기 위해 gotoxy() 함수를 사용한다.
예시 코드:

c
void gotoxy(int x, int y) {
    COORD Pos = {x - 1, y - 1};
    SetConsoleCursorPosition(GetStdHandle(STD_OUTPUT_HANDLE), Pos);
}
이를 통해 좌표를 지정하여 문자열이나 그래픽 요소를 원하는 위치에 배치할 수 있다.

3. 화면 지우기
콘솔 화면을 초기화하는 방법은 다음과 같다:

Visual C++: system("cls");

Turbo C/C++: clrscr();

이를 활용하면 반복적인 출력 시 화면을 깔끔하게 유지할 수 있다.

4. 입력 처리: ASCII 코드와 스캔 코드
ASCII 코드: 문자에 대응하는 약속된 값 (예: 'a' → 97).

스캔 코드: 키보드의 물리적 키에 대응하는 값. 화살표 키, Home, End 등은 확장 코드로 처리된다.
예시: 위쪽 화살표 키 → 72, 아래쪽 화살표 키 → 80.

5. 화살표 키 이동
화살표 키 입력을 통해 객체를 이동시키는 함수:

c
void move_arrow_key(char key, int *x, int *y, int x_b, int y_b) {
    switch(key) {
        case 72: (*y)--; if(*y < 1) *y = 1; break; // 위
        case 80: (*y)++; if(*y > y_b) *y = y_b; break; // 아래
        case 75: (*x)--; if(*x < 1) *x = 1; break; // 왼쪽
        case 77: (*x)++; if(*x > x_b) *x = x_b; break; // 오른쪽
    }
}
이를 통해 콘솔 화면에서 캐릭터를 자유롭게 이동시킬 수 있다.

6. 도형 그리기
텍스트 모드에서는 확장 문자 코드(─, │, ┌, ┐ 등)를 활용하여 사각형이나 격자를 표현한다.
예시: 정사각형을 그리는 함수는 반복문을 통해 테두리를 출력하고 내부를 공백으로 채운다.

7. 메뉴 시스템
게임 내 선택지를 제공하기 위해 메뉴 구조를 구현한다.

메인 메뉴: 햄버거, 스파게티, 프로그램 종료

서브 메뉴: 햄버거(치킨버거, 치즈버거), 스파게티(토마토, 크림)

이를 통해 사용자는 키보드 입력으로 원하는 항목을 선택할 수 있다.

8. 난수 생성
게임에서 랜덤 요소를 구현하기 위해 rand() 함수를 사용한다.

주사위: rand()%6 + 1

로또: rand()%45 + 1

중복 없는 난수: 배열과 중복 검사 반복문을 활용

난수는 게임의 예측 불가능성과 재미 요소를 강화한다.

9. 가변 인수 함수
printf, scanf와 같이 인수 개수가 변할 수 있는 함수를 직접 구현할 수 있다.
예시:

c
double sum(int count, ...) {
    va_list ap;
    va_start(ap, count);
    double total = 0;
    for(int i=0; i<count; i++) {
        total += va_arg(ap, double);
    }
    va_end(ap);
    return total;
}
