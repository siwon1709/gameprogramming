# gameprogramming

📘 게임프로그래밍 수업 레포트 (2026학년도 2학기)
1. 교과목 개요
본 과목은 게임 개발의 기본 원리를 이해하고, 실제 게임 개발 도구를 활용하여 게임을 설계 및 구현하는 능력을 기르는 것을 목표로 한다. C 언어 기반의 로직 구현부터 Unity 및 Unreal Engine을 활용한 2D/3D 게임 개발까지 폭넓게 다루며, 물리 엔진, 게임 루프, 입력 처리, 충돌 판정, 씬 전환, UI 구성 등 실무에서 필요한 핵심 요소들을 실습 중심으로 학습한다.

“C 언어를 기반으로 한 로직 구현부터, Unity 및 Unreal Engine을 활용한 2D 및 3D 게임 개발에 이르기까지 게임 프로그래밍 전반을 실습 중심으로 학습한다.”

2. 수업 목표
C 언어 게임: 기본적인 로직 구현 및 텍스트 기반 게임 제작

웹 게임: HTML5와 JavaScript를 활용한 브라우저 기반 게임 개발

유니티 게임: Unity 엔진을 활용한 2D/3D 게임 설계 및 구현

언리얼 게임: Unreal Engine을 통한 고급 그래픽 및 물리 기반 게임 제작

3. 수업 방식
대면 강의 + 실습 중심

GitHub를 활용한 코드 관리 및 협업 훈련

프로젝트 3개 발표 필수 (텍스트 모드, 웹 게임, Unity/Unreal 게임)

학생 참여 활동: 과제, 발표, 실습, 깃허브 정리

4. 평가 방식
평가 항목	비율	세부 기준
출석	10%	성실한 참여
중간시험	30%	게임 제작 및 이해도
기말시험	30%	게임 제작 및 이해도
과제물	20%	수업 중 제작 파일 및 독창성
발표	10%	논리성, 충실성, 주제 적합성, 전달력


5. 교재 및 참고문헌
(초보자를 위한) 유니티 5 입문 – 아라카와 다쿠야 외, 한빛미디어

만들면서 배우는 HTML5 게임 프로그래밍 – 황동윤, 한빛미디어

명품 C언어 프로젝트 – 안기수, 생능출판사

6. 15주차 수업 계획 요약
1~4주: 개발환경 구축, 코드와 라이브러리, 게임 모듈 학습

5주: 프로젝트 1 발표 (텍스트 모드 게임)

6~7주: HTML5와 자바스크립트, 캔버스 그래픽

8주: 중간고사

9주: 프로젝트 2 발표 (웹 게임)

10~12주: Unity 실습 (밸런스 게임, 캐릭터 움직임, RUN 게임)

13주: Unreal Engine 입문

14주: 프로젝트 3 발표 (Unity/Unreal 게임)

15주: 기말고사

7. 수업 규칙 및 유의사항
무단 결석 2회 이상 시 A 그룹 제외

학기 말까지 3개 프로젝트 발표 필수

영타 300타 이상 요구

사전 준비: 컴퓨터 개론 숙지

📌 레포트 결론
이 과목은 단순히 이론을 배우는 것이 아니라, 실제 게임을 직접 제작하고 발표하는 과정을 통해 실무 능력을 기르는 데 중점을 둔다. C 언어로 시작해 웹, Unity, Unreal까지 확장되는 커리큘럼은 학생들에게 게임 프로그래밍의 전반적인 흐름을 경험하게 하며, GitHub를 통한 협업 훈련은 현업 개발 환경과 유사한 경험을 제공한다.

즉, 이 수업은 게임 개발자로 성장하기 위한 실질적인 발판을 마련해주는 과정이라 할 수 있다.
