AI 사용권장

기존 코드를 업그레이드 시켜서 업그레이드 개수 : 30점중에 몇점. (30개 정도 바꾸면 만점) 

나의주제 : 10_2_1

==========================================

1. 오디오 & 사운드 시스템 (5개)
[Upgrade 01] 키패드 터치 효과음: 숫자 키를 누를 때마다 실제 2G 폰 특유의 전자 비프음(Beep(freq, time)) 출력.

[Upgrade 02] 음계 매핑 (버튼음 차별화): 1~9번 버튼마다 주파수(도, 레, 미...)를 다르게 설정하여 누르는 번호마다 다른 톤의 멜로디 재생.

[Upgrade 03] 전송/완료 팡파르: 엔터를 눌러 문장을 전송하거나 미션 성공 시 승리 멜로디 연주.

[Upgrade 04] 오타/에러 경고음: 잘못된 키 입력이나 백스페이스 한계 도달 시 낮은 단발 경고 비프음 발생.

[Upgrade 05] 소리 On/Off 음소거 토글: M 키 등을 통해 소리 켜기/끄기 설정 지원.

2. 그래픽 & 비주얼 & 콘솔 UI (5개)
[Upgrade 06] 콘솔 텍스트 색상 커스텀 (SetConsoleTextAttribute): 키패드 테두리, 숫자, 문자, 액정 화면의 색상을 다채롭게 분리(예: 초록색 레트로 액정).

[Upgrade 07] 휴대폰 안테나 및 배터리 표시: 상단 상태바에 통신사 안테나(■■■■)와 배터리 잔량([■■■□]) 그래픽 출력.

[Upgrade 08] 현재 누른 키 실시간 하이라이트: 키를 누르는 순간 해당 키패드 블록의 배경색이 순간적으로 반전되었다가 돌아오는 시각적 피드백.

[Upgrade 09] 전용 액정 화면(LCD Display Box): 키패드 상단에 문자가 타이핑되는 별도의 3줄 액정 창 프레임 구현.

[Upgrade 10] 깜빡이는 커서(Blinking Cursor): 글자가 입력되는 위치에 0.5초 주기로 _ 깜빡임 연출.

3. 인트로 & 메뉴 & 화면 전환 연출 (4개)
[Upgrade 11] 애니메이션 부팅 인트로: 전원 켜짐 로고 애니메이션("CYON / ANYCALL") 및 부팅 효과음.

[Upgrade 12] 메인 메뉴 시스템: 1. 자유 문자 작성, 2. 단문 타자 검정(게임), 3. 문자 보관함, 4. 종료.

[Upgrade 13] 화면 전환 애니메이션: 메뉴 이동 시 콘솔을 단순 cls하지 않고 텍스트 창이 스크롤되거나 페이드되는 연출.

[Upgrade 14] 종료 화면 (Power Off): 종료 시 "안녕히 가세요" 메시지와 함께 전원이 꺼지는 딜레이 연출.

4. 입력 엔진 & 로직 고도화 (6개)
[Upgrade 15] 특수문자 및 기호 입력 모드 (* 키): * 키를 누르면 !, ?, @, #, , 등의 특수문자 선택 창 팝업.

[Upgrade 16] 대/소문자 전환 모드 (# 키): # 키를 누를 때마다 소문자(abc) ↔ 대문자(ABC) ↔ 숫자(123) 모드 순환.

[Upgrade 17] 글자 확정 타이머 바 (Visual Timer): 2초 내 재입력 제한 시간을 우측에 게이지(■■□□) 형태로 실시간 시각화.

[Upgrade 18] 즉시 확정 키(방향키 우측 →) 지원: 같은 키의 다음 글자를 칠 때 2초를 기다리지 않고 →를 눌러 바로 다음 글자로 이동.

[Upgrade 19] 백스페이스(Backspace) 글자 삭제 지원: 기존 코드에서 안 되던 완성 글자 단위 삭제 로직 구현.

[Upgrade 20] 띄어쓰기(Space) 처리 개선: 0번 키 또는 스페이스바를 누를 때 공백이 정확하게 액정에 반영되도록 수정.

5. 타자 게임 모드 & 측정 기능 (5개)
[Upgrade 21] 2G 타자 검정 게임 모드: 랜덤으로 제시되는 영문 문장("HELLO WORLD" 등)을 피처폰 키패드로 똑같이 치는 미니게임.

[Upgrade 22] 타자 속도(WPM / CPM) 계산: clock()을 사용해 문장을 완성하는 데 걸린 분당 타수 정밀 측정.

[Upgrade 23] 정확도(Accuracy %) 계산: 입력된 문장과 목표 문장을 비교해 일치율(%) 출력.

[Upgrade 24] 콤보 시스템: 오타 없이 연속으로 글자를 입력할 때마다 "COMBO x2, x3" 보너스 점수 부여.

[Upgrade 25] 제한시간 타임어택 모드: 30초 안에 최대한 많은 단어를 입력하는 도전 모드.

6. 파일 입출력 (Data Persistence) (2개)
[Upgrade 26] 보낸 문자 메시지 파일 저장: 작성한 문장을 outbox.txt 파일에 타임스탬프(날짜/시간)와 함께 영구 저장.

[Upgrade 27] 타자 게임 역대 랭킹 파일 기록: 게임 최고 점수(닉네임, 타수, 일자)를 ranking.txt에 저장하고 TOP 5 조회 기능 제공.

7. 코드 품질 & 모던 C++ & 안정성 (3개)
[Upgrade 28] C++ 객체지향(OOP) 클래스화: 절차형 함수들을 PhonePad, Display, GameManager 클래스로 분리 캡슐화.

[Upgrade 29] 입력 버퍼 안정화 및 예외 방어: 정의되지 않은 키 입력 시 콘솔이 먹통 되거나 튕기지 않도록 방어 로직 구축.

[Upgrade 30] 동적 메모리/컨테이너(std::string, std::vector) 적용: 고정 크기 C 스타일 char 배열을 std::string과 STL 컨테이너로 리팩터링.
